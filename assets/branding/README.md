# AI Code Review Agent branding

The approved branding family is committed as actual PNG image files and editable SVG masters. The SVG artwork is a vector **adaptation**, not an exact trace of the originally generated concept.

## Available assets

- `logo.svg` and `logo-1024.png` — full logo on dark navy for README and portfolio.
- `logo-transparent.svg` and `logo-transparent-1024.png` — transparent-background wordmark.
- `icon.svg` — scalable square symbol.
- `icon-small.svg` — simplified vector mark for smaller presentation sizes.
- `icon-32.png`, `icon-64.png`, `icon-128.png`, `icon-256.png`, `icon-512.png`, `icon-1024.png` — exported PNG icon sizes.
- `icon-monochrome-dark.svg`, `icon-monochrome-light.svg` — monochrome variants for appropriate backgrounds.
- `social-preview.svg` and `social-preview-1280x640.png` — GitHub sharing preview source and image.

The original raster concepts remain in the separate downloadable branding kit, rather than adding >1 MB of generated reference imagery to this repository.

## GitHub social preview

The PNG file **is committed here**, but GitHub's repository **Settings → General → Social preview → Edit** setting must still be configured separately using `social-preview-1280x640.png`. Committing an image does **not** automatically activate it as the repository's social preview. No repository administration setting was changed in this PR.

Palette: navy `#020B22`, electric blue `#086BFF`, cyan `#05ECF7`, mint `#00E8C4` and (ACR diff) coral `#FF496A`.

Branding is documentation/media only: no runtime, package, CI, tests, release gates or global agent configuration changed.
