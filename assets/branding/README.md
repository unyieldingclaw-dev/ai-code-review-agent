# AI Code Review Agent branding

The approved concept has been redrawn as genuine editable vector artwork. The SVG master is a vector **adaptation** of the original generated raster, not a pixel-perfect automatic trace.

- `logo.svg`: primary logo on dark navy; intended for README and portfolio pages.
- `icon.svg`: scalable transparent icon for use as a project mark.

The full approved branding kit (transparent PNG, 32/64/128/256/512/1024 px icons, simplified small icon, monochrome designs, and GitHub social preview 1280×640) is packaged separately for review. GitHub's **Social preview** image must be uploaded as a PNG through repository settings; committing the SVG alone does not configure that setting.

Palette: navy `#020B22`, blue `#086BFF`, cyan `#05ECF7`, mint `#00E8C4` and, for ACR's diff visualization, red `#FF496A`.

These branding assets do not affect project runtime, packaging, tests, install paths or release gates.
